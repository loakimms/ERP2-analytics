# 다운로드한 CDP 실행 파일 사용 방법 (일반 사용자용)

Analytics **내 상품 추적** 수집 시 사용하는 **"호스트 크롬(CDP) 전용 창"**을 Cursor/터미널 없이 띄우는 방법입니다.

---

## 1. 실행 파일 받기

1. **Analytics 웹**에 접속합니다. (예: http://localhost:5188)
2. **내 상품 추적** 메뉴로 들어갑니다.
3. 상품이 있으면 **수집** 관련 버튼을 눌러 **수집 모달**을 엽니다.
4. 모달 안 **1단계**에서 **「실행 파일 받기(일반 사용자용)」** 링크를 클릭합니다.
5. 브라우저가 `Start-Analytics-HostChrome.ps1` 파일을 **다운로드**합니다.
   - 보통 **다운로드** 폴더에 저장됩니다.
   - 원하면 **바탕화면**이나 **문서** 폴더로 옮겨 두어도 됩니다.

---

## 2. 실행 파일 실행하기 (CDP 전용 Chrome 띄우기)

### 방법 A: 우클릭으로 실행 (권장)

1. **파일 탐색기**에서 다운로드한 `Start-Analytics-HostChrome.ps1` 파일을 찾습니다.
2. 해당 파일에서 **마우스 우클릭**합니다.
3. 메뉴에서 **「PowerShell로 실행」**을 클릭합니다.
   - 메뉴에 "PowerShell로 실행"이 없으면:
     - **「연결 프로그램」** → **「다른 앱 선택」** → **Windows PowerShell** 선택 후 실행
     - 또는 아래 **방법 B**를 사용합니다.
4. **검은 창(PowerShell)**이 잠깐 뜨고, 곧이어 **Chrome 창**이 새로 열립니다.
   - 이 Chrome 창이 **CDP 전용 창**입니다. (처음에는 네이버 쇼핑 검색 페이지가 보일 수 있습니다.)
5. PowerShell 창에 `✅ Host Chrome started for CDP reuse` 같은 문구가 보이면 성공입니다. 그 창은 닫아도 됩니다.

### 방법 B: PowerShell에서 실행 (우클릭 메뉴가 없을 때)

1. **시작 메뉴**에서 **Windows PowerShell** 또는 **터미널**을 검색해 엽니다.
2. 아래 명령을 **한 줄씩** 입력합니다. (경로는 본인이 저장한 위치로 바꿉니다.)
   ```powershell
   cd $env:USERPROFILE\Downloads
   .\Start-Analytics-HostChrome.ps1
   ```
   - 파일을 **다운로드**가 아닌 **바탕화면**에 두었다면:
     ```powershell
     cd $env:USERPROFILE\Desktop
     .\Start-Analytics-HostChrome.ps1
     ```
3. **실행 정책** 관련 오류가 나오면, 아래를 **한 번만** 실행한 뒤 다시 시도합니다.
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```
4. Chrome 창이 새로 뜨면 성공입니다.

---

## 3. 실행 후 할 일 (수집 2~4단계)

CDP 전용 Chrome이 떴다면, 아래 순서대로 진행합니다.

| 단계 | 할 일 |
|------|--------|
| **2** | **방금 뜬 Chrome 창**에서 **네이버/스마트스토어 로그인**을 합니다. (2단계 인증까지 완료.) |
| **3** | Analytics 웹 수집 모달로 돌아가 **「호스트 크롬에서 상품 페이지 열기(세션)」** 버튼을 누릅니다. (해당 Chrome 창에 상품 페이지 탭이 열립니다. 보안 확인이 뜨면 그 창에서 직접 해결합니다.) |
| **4** | 로그인·보안 확인이 끝났다면 수집 모달에서 **「지금 수집」** 버튼을 눌러 수집을 실행합니다. |

**주의**:  
- 로그인·쇼핑 접속·보안 확인은 **반드시 CDP 전용 Chrome 창**에서만 해야 합니다.  
- 평소 쓰는 Chrome 창이 아니라, **실행 파일로 띄운 그 창**에서 진행해야 Analytics 수집이 정상 동작합니다.

---

## 4. 자주 묻는 것

### Q. 더블클릭했는데 실행이 안 돼요.

- Windows는 보안상 `.ps1` 파일을 더블클릭해도 **바로 실행되지 않을 수** 있습니다.
- **우클릭 → 「PowerShell로 실행」**을 사용하세요. (위 2. 방법 A)
- 그래도 안 되면 **방법 B**처럼 PowerShell을 열고 `.\Start-Analytics-HostChrome.ps1` 로 실행하세요.

### Q. "Chrome 실행 파일을 찾지 못했습니다"라고 나와요.

- PC에 **Google Chrome**이 설치되어 있어야 합니다.
- Chrome을 설치한 뒤 다시 실행 파일을 실행해 보세요.

### Q. 실행 파일은 매번 받아야 하나요?

- **한 번 받아 두면** 같은 파일을 계속 사용해도 됩니다.
- Analytics 웹을 **업데이트(재배포)** 한 뒤에는, 필요하면 다시 **「실행 파일 받기」**로 최신 파일을 받는 것을 권장합니다.

### Q. CDP 전용 Chrome 창을 닫으면 어떻게 되나요?

- 창을 닫으면 **CDP 세션이 끝난 것**입니다.
- 다시 수집하려면 **실행 파일을 다시 실행**해 새 CDP 창을 띄운 뒤, 2~4단계를 반복하면 됩니다.

### Q. 포트 충돌(9223) 메시지가 나와요.

- 이미 다른 프로그램이 9223 포트를 쓰고 있을 수 있습니다.
- **기존에 띄워 둔 CDP 전용 Chrome 창**이 있으면 먼저 닫고 다시 실행해 보세요.
- 그래도 안 되면, PowerShell에서 **다른 포트**로 실행할 수 있습니다.
  ```powershell
  .\Start-Analytics-HostChrome.ps1 -Port 9224
  ```
  (단, 포트를 바꾸면 Analytics API 설정도 9224로 맞춰야 할 수 있어, 운영 담당자와 확인하는 것이 좋습니다.)

---

## 5. 요약

1. **실행 파일 받기**: Analytics 웹 → 내 상품 추적 → 수집 모달 → 「실행 파일 받기(일반 사용자용)」
2. **실행**: 받은 `Start-Analytics-HostChrome.ps1` **우클릭 → PowerShell로 실행**
3. **CDP 전용 Chrome**이 뜨면, **그 창에서** 로그인·보안 확인 후, 웹에서 **상품 페이지 열기** → **지금 수집** 순서로 진행

Cursor나 터미널 없이 **파일 다운로드 + 우클릭 실행**만으로 1단계(CDP 창 띄우기)를 할 수 있습니다.
